# javascript-lotto-precourse

# 로또

이번 미션은 간단한 로또 발매 및 당첨 결과 확인을 구현한 콘솔 Application입니다.
사용자는 로또 구입 금액을 입력하고 발행된 로또를 확인한 후 당첨 번호와 보너스 번호를 입력하여 당첨되었는지 확인하고 수익률을
계산할 수 있습니다.

---

<br>

# 기능 목록

## 1. 로또 구입 금액 입력

- [x] 로또 구입 금액을 입력 받는다.
- [x] 구입 금액은 1,000원 단위로 입력 받는다.
  - [x] 예외: 빈 문자열 또는 공백을 입력한 경우
  - [x] 예외: 숫자가 아닌 값을 입력한 경우
  - [x] 예외: 구입 금액이 0원 이하인 경우
  - [x] 예외: 1,000원으로 나누어 떨어지지 않는 경우

## 2. 로또 발행

- [x] 로또 1장의 가격( 1,000원 )으로 나눈 값만큼 발행할 로또 수량을 결정한다.
- [x] 로또 수량에 해당하는 만큼 로또를 발행한다.
- [x] 발행한 로또를 오름차순으로 정렬한다.

## 3. 발행한 로또 수량, 번호 출력

- [x] 발행한 로또 수량을 출력한다.

  - ex) `8개를 구매했습니다.`

- [x] 발행한 로또를 출력한다.

  - ex)

  ```text
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    [7, 11, 16, 35, 36, 44]
    [1, 8, 11, 31, 41, 42]
    [13, 14, 16, 38, 42, 45]
    [7, 11, 30, 40, 42, 43]
    [2, 13, 22, 32, 38, 45]
    [1, 3, 5, 14, 22, 45]
  ```

## 4. 당첨 번호 입력

- [x] 당첨 번호를 입력받는다.
- [x] ,(쉼표)를 기준으로 입력받은 당첨 번호를 분리한다.
  - [x] 예외: 분리된 당첨 번호가 6개가 아닌 경우
  - [x] 예외: 숫자가 아닌 값이 있는 경우
  - [x] 예외: 각 숫자가 1 ~ 45 사이의 숫자가 아닌 경우
  - [x] 예외: 중복된 숫자가 있는 경우

## 5. 보너스 번호 입력

- [x] 보너스 번호를 입력받는다.
  - [x] 예외: 숫자가 아닌 경우
  - [x] 예외: 1 ~ 45 사이의 숫자가 아닌경우
  - [x] 예외: 당첨 번호와 중복인 경우

## 6. 구매한(발행된) 로또 번호와 당첨 번호 비교

- [x] 발행된 각 로또 번호와 당첨 번호가 일치하는 숫자를 계산한다.
- [x] 3개의 번호 이상으로 일치하면 당첨 내역에 기록한다.
- [x] 5개의 번호 일치 시 보너스 번호와 일치하는 지 추가로 확인한다.

## 7. 당첨 내역 출력

- [x] 당첨 내역을 출력한다.

  - ex)

  ```text
   3개 일치 (5,000원) - 1개
   4개 일치 (50,000원) - 0개
   5개 일치 (1,500,000원) - 0개
   5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
   6개 일치 (2,000,000,000원) - 0개
  ```

## 8. 수익률 계산

- [x] 당첨된 당첨 금액을 모두 더한다.
- [x] 수익률 ( 총 당첨 금액 / 구입 금액 ) X 100 을 계산한다.
- [x] 소수점 둘째 자리에서 반올림한다.

## 9. 수익률 출력

- [x] 수익률을 출력한다.
  - ex) `총 수익률은 62.5%입니다.`

## 예외

- [x] `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시킨다.
  - ex) `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`
- [x] 에러가 발생한 지점부터 다시 입력을 받는다.
